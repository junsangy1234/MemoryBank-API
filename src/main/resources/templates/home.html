Google OAuth Compliance & Application Disclosure

1. Application Purpose (애플리케이션 목적)

AI Memory Bank is a Chrome extension that helps users save, search, and manage AI conversation memories across multiple AI platforms. (AI Memory Bank는 사용자가 여러 AI 플랫폼에서 나눈 대화 기록과 지식을 효율적으로 저장, 검색, 관리할 수 있도록 돕는 Chrome 확장 프로그램입니다.)

2. Purpose of Google Sign-In (Google 로그인을 사용하는 이유)

Google Sign-In is strictly used for secure user authentication and to facilitate cross-device memory synchronization. This ensures that your personal knowledge base is safely linked only to your verified identity. (Google 로그인 인증은 사용자의 안전한 신원 확인 및 기기 간 메모리 데이터 동기화를 위해서만 안전하게 사용됩니다.)

3. Data Storage & Privacy Protection (저장 데이터 및 정보 보호)

User memories and saved AI interactions are securely stored and encrypted in our isolated backend database. We never sell your data or utilize your personal memories to train AI models. (사용자가 저장한 대화 메모리와 데이터는 격리된 데이터베이스에 암호화되어 안전하게 보관되며, 마케팅 목적으로 판매되거나 외부 AI 모델 학습에 절대 활용되지 않습니다.)

4. Chrome Extension Integration (Extension 연동 설명)

This web application works directly with the official AI Memory Bank Chrome Extension. The extension securely communicates with this domain to capture web content and dynamically inject relevant context via the /m command. (본 웹 애플리케이션은 AI Memory Bank 크롬 확장 프로그램과 연동되어 작동하며, 브라우저 상의 텍스트 캡처 및 웹상의 콘텍스트 주입 기능을 제공합니다.)
